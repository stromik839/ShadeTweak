# ShadeTweak — свой цвет и прозрачность фона шторки HyperOS

LSPosed-модуль для HyperOS 2 (Android 15). Он меняет фон шторки уведомлений и
Центра управления, который HyperOS рисует при выключенном блюре (по умолчанию
серый `#FF6E6E6E`). Можно задать любой цвет, любую прозрачность, в том числе
полностью прозрачный фон. Изменения применяются сразу, без перезапуска SystemUI.

## Что было не так в версии 1.0 и что исправлено в 2.0

Разбор сделан по `MiuiSystemUI.apk` 20240808.0 и `MiuiSystemUIPlugin.apk`
16.0.5.18.0.

1. **Настройки часто не доходили до SystemUI.** В 1.0 они передавались через
   `XSharedPreferences` из `MODE_PRIVATE`-файла. SystemUI не может прочитать
   такой файл (права и SELinux), поэтому хук молча брал значения по умолчанию.
   Отсюда «цвет то меняется, то нет» и нерабочая полная прозрачность.
   **Теперь** настройки лежат в `Settings.Global`: SystemUI читает их всегда и
   получает изменения сразу через `ContentObserver`.
2. **Скриншот-блюр.** Если `ShadeBlurController.screenshotBlur = true` (на части
   устройств он включён по умолчанию), фоном шторки становится размытый
   скриншот или серый `ColorDrawable` прямо из ресурсов. Поля
   `solidAlpha/solidRGB`, которые подменяла 1.0, в этом режиме не используются
   вообще. **Теперь** модуль может выключить этот режим (переключатель
   «Отключать скриншот-блюр»).
3. **Центр управления на экране блокировки** рисуется отдельным методом
   `updateCtrl$1()`, а 1.0 его не перехватывала. **Теперь** перехватывается.
4. **Хук только «перед updateWindow»** мог пропускаться, если ART заинлайнил
   вызов. **Теперь** значения держатся прямо в полях контроллера: они ставятся
   после `start()`, после `access$updateResources` (смена темы) и перед каждой
   перерисовкой. Методы, которые делают эти вызовы, деоптимизируются через
   LSPosed.
5. Убраны потоки с повторами и `ClassNotFoundException`. Хуки ставятся один раз
   в тот classloader, где реально есть класс.
6. Убран экспериментальный хук `ScrimController`: в состоянии `UNLOCKED`
   HyperOS сама обнуляет эти скримы, так что он ничего не делал.
7. Бонус: тот же цвет можно поставить фону модального окна уведомления
   (`BlurUtilsExt.solidColor*`). Там тоже был `#FF6E6E6E`.

### Как HyperOS 2 рисует фон шторки без блюра

- `com.miui.systemui.shade.blur.ShadeSolidBackgroundController`:
  - `updateWindow()` — view `shade_background` в окне шторки (уведомления и
    Центр управления поверх рабочего стола);
  - `updateCtrl$1()` — такой же view в `ControlCenterContainer` (шторка на
    экране блокировки);
  - цвет = `solidRGB | (solidAlpha * степень_раскрытия) << 24`.
- Если включён системный блюр (`miBlurOpen` или `windowBlurAvailable`), этот
  фон не рисуется совсем и работает блюр. Поэтому модуль нужен только при
  выключенном блюре.
- Плагин Центра управления (`miui.systemui.plugin`) свою подложку не рисует,
  он только передаёт `blurRatio` в SystemUI.

## Установка

### Что нужно на телефоне
1. Root (KernelSU / Magisk).
2. ZygiskNext (для KernelSU) и LSPosed (JingMatrix/LSPosed).
3. Блюр шторки выключен (например через `deviceLevelList`, как раньше).

### Сборка (GitHub Actions)
APK собирается автоматически при каждом push: вкладка **Actions** → последний
запуск → **Artifacts** → `ShadeTweak-apk`.

Локально: Android Studio → Build → Build APK(s); результат лежит в
`app/build/outputs/apk/debug/app-debug.apk`.

### Установка APK
1. Установи APK. Подпись та же, что у 1.0 (`debug.keystore` в репозитории),
   поэтому APK ставится поверх старой версии.
2. LSPosed → Модули → **Shade Tweak** → включить, область: «Системный
   интерфейс» (`com.android.systemui`).
3. Перезапусти SystemUI (кнопка в приложении) или перезагрузи телефон.

### Настройка
Открой **Shade Tweak**:
- «Заменить фон шторки» — включить или выключить замену;
- превью на шахматке показывает и цвет, и прозрачность;
- слайдеры «Непрозрачность / Красный / Зелёный / Синий» или поле `AARRGGBB`;
- готовые варианты: «Прозрачный» (`00000000`), «Тень 30%», «Тёмный 60%»,
  «Чёрный», «Белый 25%», «Системный».

Цвет применяется сразу после отпускания слайдера или нажатия на вариант.
При первом сохранении KernelSU попросит root. Он нужен один раз: приложение
выдаёт себе `WRITE_SECURE_SETTINGS`, дальше пишет настройки само.

Вверху приложения есть **статус**, который присылает сам хук из SystemUI:
работает ли модуль, нет ли включённого блюра или скриншот-блюра.

### Без приложения (вручную)
```
su -c settings put global shadetweak_color 00000000   # AARRGGBB
su -c settings put global shadetweak_enabled 1        # 0 — вернуть системный фон
su -c settings put global shadetweak_force_solid 1    # выключать скриншот-блюр (нужен перезапуск SystemUI)
su -c settings put global shadetweak_modal 1          # тот же цвет для модального окна уведомления
su -c settings get global shadetweak_status           # что видит хук
```

## Если не работает

LSPosed → Логи, ищи `ShadeTweak`:
- `vX: SystemUI найден, ставлю хуки` и `установлено хуков: 7` — всё на месте;
- `настройки изменены: enabled=true color=...` — изменения из приложения доходят;
- `системный screenshotBlur=true` и `скриншот-блюр выключен` — модуль выключил
  скриншот-блюр;
- `... не найден` — в этой сборке HyperOS классы называются иначе. Пришли этот
  лог и `MiuiSystemUI.apk` со своей прошивки.

Если в статусе написано «включён системный блюр», то в шторке работает
настоящий блюр, а сплошной фон, который меняет модуль, не рисуется.
